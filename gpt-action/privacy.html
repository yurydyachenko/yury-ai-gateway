Yury AI Panel privacy notice

This GitHub Pages site is a static setup guide. It does not collect, transmit, or store API keys, prompts, or model responses.

When the configured ChatGPT Action is used, ChatGPT sends the selected prompt and necessary context directly to the Perplexity Agent API at api.perplexity.ai. There is no Yury AI Panel proxy server or database.

OpenAI and Perplexity process data under their respective privacy policies and account settings. Do not submit credentials or data that you are not authorized to share.

Authentication

The Perplexity API key must be entered only in the GPT editor's encrypted Action authentication field. It must never be entered on this site or committed to GitHub.
