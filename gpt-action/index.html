Yury AI Panel

A direct ChatGPT Action for Perplexity research, Claude review, and Grok reasoning. GitHub hosts only this setup package; ChatGPT calls Perplexity directly.

  1. Open the GPT Builder and create a GPT called “Yury AI Panel.”
  2. Copy the ready-made instructions into its Instructions box.
  3. Add an Action, choose “Import from URL,” and paste the copied schema URL.
  4. Set Authentication to API Key → Bearer. Paste your Perplexity key only into ChatGPT’s secure authentication field.
  5. Save as “Only me.” On the first call, choose “Always allow” for one-click use after that.
